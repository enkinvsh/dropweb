# Маяк зеркал подписки

`sub-beacon.json` — подписанный (Ed25519) список адресов, по которым приложение dropweb
ищет подписку, когда все известные ему адреса не отвечают. Шаблоны содержат `{id}` —
приложение подставляет свой идентификатор подписки; токенов и личных данных в файле нет.

Файл не правят руками: его выпускает `tool/sign_sub_beacon.dart` из основной ветки,
каждый новый документ — с бо́льшим `seq`. Контракт — `docs/subscription-headers.md`, §10.
