# TLS Fragment (фрагментация TLS)

TLS Fragment — управляемая оператором функция обхода DPI-фильтрации. Она дробит первый TLS ClientHello на несколько TCP-сегментов, разделяя SNI между ними. Сервер собирает обычный TCP-поток, а промежуточному DPI сложнее сопоставить имя хоста в одном сегменте.

## Источник истины

Параметры задаются только серверным Mihomo-шаблоном Remnawave. В приложении нет локального переключателя или сохранённого значения: пользователь не может переопределить политику оператора.

Ключи должны находиться **в корне итогового Mihomo YAML**, а не во вложенной секции `general`:

```yaml
tls-fragment: true
tls-fragment-size: 8
tls-fragment-delay: 5
```

Remnawave переносит структуру шаблона без разворачивания `general`, а xHomo читает эти параметры как корневые поля.

## Параметры

| Параметр | Назначение | Значение по умолчанию |
|---|---|---|
| `tls-fragment` | Включает глобальную фрагментацию TCP TLS ClientHello | `false` |
| `tls-fragment-size` | Максимальный размер части SNI в байтах | `8` |
| `tls-fragment-delay` | Задержка между частями в миллисекундах | `5` |

## Область действия

- Обрабатывается только первый TLS ClientHello TCP-соединения.
- Корневой флаг действует на все TCP-dial, включая соединения, отправленные правилами через `DIRECT`; при задержке `5` мс это добавляет небольшой overhead к установке каждого подходящего TLS-соединения.
- Первый пакет не-TLS проходит без изменений.
- Если SNI не удалось разобрать, ClientHello делится на три части.
- UDP/QUIC-транспорты, включая Hysteria2, этой TCP-фрагментацией не затрагиваются.

Реализация находится в `core/Clash.Meta/component/dialer/tlsfragment.go`. При первом фактическом применении ядро пишет `[TLSFragment] active`.

## Проверка

1. Проверить, что три ключа присутствуют в корне сгенерированной Remnawave-подписки.
2. Обновить профиль и переподключить VPN.
3. Выполнить TLS-запрос через TCP-прокси.
4. После полного перезапуска процесса ядра найти одноразовое info-сообщение `[TLSFragment] active`. Для повторной диагностики каждого ClientHello временно нужен `log-level: debug`, где ядро пишет `[TLSFragment] ClientHello ...`.
